# 🛡️ Chavatte Security Store // CasaOS

🇺🇸 **English**

Welcome to the official third-party CasaOS App Store maintained by **Chavatte Security**.
This repository provides 1-click deployments for tactical DevSecOps tools, Threat Intelligence dashboards, and secure infrastructure for your HomeLab.

### 📦 Featured Applications

* **Sentinel Ops (v2.0.0+):** Advanced Threat Intelligence & Vulnerability Monitor for Node.js Ecosystems. Features an Executive SecOps Dashboard, SQLite Engine tracking MTTR, and Auto-Governance.

### ⚙️ How to install on CasaOS

To add this custom store to your CasaOS server, follow these steps:

1. Open your CasaOS web interface.
2. Click on the **App Store** icon.
3. Click on the **Add Source** button (or the `+` icon on the right side).
4. Copy and paste the archive link below:

```text
https://github.com/chavatte/chavatte-casaos-store/archive/refs/heads/main.zip
```


5. Click **Add** and wait for the refresh. You will now see the Chavatte Security apps available for installation!
